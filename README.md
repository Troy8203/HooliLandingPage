# Hooli Landing-Page

Este es un sitio web creado para la ficticia empresa Hooli, popularizada en la serie *Silicon Valley*. La landing page está diseñada para servir como una introducción visual y funcional al estilo de la empresa Hooli, destacando su enfoque en la innovación tecnológica. Este proyecto es ideal para principiantes que deseen familiarizarse con el desarrollo web básico, utilizando una combinación de tecnologías frontend y un generador de sitios estáticos para la renderización de contenido.

## Características Principales

Este proyecto se centra en proporcionar una experiencia de usuario sencilla y accesible, mientras permite a los desarrolladores novatos explorar y aplicar tecnologías esenciales para la creación de sitios web. A continuación, se detallan las principales características del sitio:

- **Estructura HTML Semántica:**  
  El sitio web utiliza HTML5 para garantizar una estructura semántica adecuada, facilitando la accesibilidad y el SEO (optimización en motores de búsqueda).

- **Diseño Responsivo:**  
  Gracias a la implementación de Bootstrap, el sitio está optimizado para verse bien en dispositivos de diferentes tamaños, desde móviles hasta monitores de escritorio.

- **Interactividad con JavaScript:**  
  Se han añadido pequeñas interacciones con JavaScript, como botones y elementos interactivos que mejoran la experiencia del usuario sin sobrecargar la página.

- **Estilización con CSS Personalizado:**  
  Además de Bootstrap, se han aplicado estilos CSS personalizados para ajustar el diseño visual al tema de Hooli, utilizando colores y tipografías representativas.

- **Renderización con Jekyll:**  
  El sitio utiliza Jekyll como generador de sitios estáticos, permitiendo la conversión de archivos Markdown a HTML, facilitando la gestión del contenido y permitiendo un despliegue rápido y eficiente.

- **Uso de Markdown para Contenido:**  
  El contenido del sitio se gestiona mediante archivos Markdown, lo que simplifica la edición y permite a los usuarios actualizar el contenido de manera sencilla.

## Instalación

El sitio está disponible en producción y se puede acceder a través del siguiente enlace: [Hooli Landing Page](https://troy8203.github.io/HooliLandingPage/).

### Ejecución Local

Si deseas abrir el sitio de forma local, sigue las siguientes instrucciones:

> Asegúrate de tener un navegador instalado. Puedes abrir el archivo principal en tu navegador preferido:

   - **Chrome:**  
     ```bash
     google-chrome _site/index.html
     ```

   - **Firefox:**
     ```bash
     firefox _site/index.html
     ```

   - **Firefox Developer Edition:**
     ```bash
     firefox-aurora _site/index.html
     ```
